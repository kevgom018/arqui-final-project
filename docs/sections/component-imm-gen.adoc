=== Immediate Generator

The Immediate Generator is a combinational component that extracts immediate values from a 32-bit RISC-V instruction. The generated immediate is used by instructions such as loads, stores, and branches.

==== Specifications

image::./images/imm_gen.png[Immediate Generator Circuit Diagram, pdfwidth=100%, align=center]

The Immediate Generator component has the following input and output signals:

[cols="1,1,3", options="header"]
.Immediate Generator Signals
|===
| Signal
| Bitwidth
| Description

| `inst`
| 32
| Full 32-bit instruction input.

| `imm8`
| 8
| 8-bit immediate output used by load and store type instructions.

| `imm_b`
| 32
| Branch immediate output used by branch instructions.
|===

The component identifies the instruction type by checking the opcode bits. Based on the instruction format, it selects the correct immediate field:

[cols="1,1,3", options="header"]
.Immediate Format Behavior
|===
| Instruction Type
| Example
| Immediate Behavior

| I-type
| `lw x1, 0(x0)`
| Extracts the immediate from bits `[31:20]` and outputs it through `imm8`.

| S-type
| `sw x2, 1(x0)`
| Reconstructs the immediate from bits `[31:25]` and `[11:7]`, then outputs it through `imm8`.

| B-type
| `beq x3, x3, 8`
| Reconstructs the branch immediate field and outputs it through `imm_b`.
|===

For the tested branch instruction `beq x3, x3, 8`, the Immediate Generator outputs `00000000000000000000000000001000` through `imm_b`, matching the branch offset used by the datapath to compute the correct branch target.

==== Testing Methodology

The Immediate Generator was tested inside CircuitVerse by manually applying known 32-bit instruction encodings to the `inst` input and observing the generated outputs `imm8` and `imm_b`.

The tests were designed to verify the following behavior:

. Correct immediate extraction for I-type load instructions.
. Correct immediate reconstruction for S-type store instructions.
. Correct branch immediate generation for B-type branch instructions.
. Correct output behavior for instructions that do not use the immediate generator path.

The complete test cases are documented in `tests/Immediate Generator Tests.csv`.

==== Verification

All test cases produced the expected immediate outputs. The I-type test confirmed that the immediate generator correctly extracts the immediate field for a load instruction. The S-type test confirmed that the component correctly reconstructs the split immediate field used by store instructions.

The B-type test confirmed that the branch immediate is generated correctly for the `beq` instruction. For `beq x3, x3, 8`, the block outputs `00000000000000000000000000001000` through `imm_b`, matching the observed CircuitVerse behavior. The non-immediate instruction tests confirmed that R-type operations and `nop` do not incorrectly activate the immediate outputs. Therefore, the Immediate Generator component is validated and ready for integration into the processor data path.
