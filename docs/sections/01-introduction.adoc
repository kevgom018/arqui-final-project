== Introduction

This report documents the testing and validation of a 32-bit RISC-V processor implemented in  https://circuitverse.org/simulator/edit/ciic4082_native_single_cycle_riscv-493de537-b42c-4f63-b8da-7b97ee345f76[CircuitVerse]. The goal is to verify the major processor components and confirm correct instruction execution across the datapath.

The project history is available in https://github.com/kevgom018/arqui-final-project[our GitHub repository].

The document is organized into three parts:

. *Part 1 - Instruction Memory Decoding*: Identification and analysis of the instruction set stored in the processor's instruction memory
. *Part 2 - Individual Component Testing*: Verification of each processor subsystem in isolation
. *Part 3 - Processor Integration Testing*: End-to-end validation of the complete processor executing the full instruction sequence

Each part includes test protocols, measurements at critical signal points using the CircuitVerse Flag element, and verification that each component or instruction meets its functional specification.

The processor operates on 8-bit data but uses 32-bit instruction and program counter (PC) values, as specified in the reference design. Flags are placed throughout the design to support signal observation and verification during simulation.
