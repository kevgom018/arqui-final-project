== Part 3: Processor Integration and Validation

After verifying individual components, the complete processor must be validated executing the full instruction sequence. This integration phase confirms that components interact correctly and that the processor achieves the intended behavior when executing real programs.

=== Signal Monitoring Points

Key signals to observe during execution include:

- Program Counter (**PC**): Current instruction address
- Current Instruction (**Inst**): The 32-bit instruction value fetched from instruction memory
- All control signals generated by the control unit:
* Opcode (**op**): The 7-bit opcode field from the instruction that determines the instruction type and control signal generation
* Function 3 (**f3**): The 3-bit funct3 field that further specifies the instruction variant for R-type, I-type, S-type, and B-type instructions
* Function 7 (**f7**): The 7-bit funct7 field that further specifies the instruction variant for R-type instructions, particularly distinguishing between operations like ADD and SUB
* Branch (**branch**): Signal indicating a branch instruction
* Memory Write (**mem_wr**): Signal indicating a write operation to data memory
* Memory Read (**mem_rd**): Signal indicating a read operation from data memory
* Memory to Register (**mem_to_reg**): Signal indicating data should be written to a register from memory
* ALU Control (**alu_ctrl**): Signal controlling the operation of the arithmetic logic unit
* ALU Source (**alu_src**): Signal determining the source of inputs for the ALU
* Register Write (**reg_wr**): Signal indicating a write operation to the register file

- ALU Inputs: The two operands fed into the ALU for each instruction
* First ALU Operand (**a**) : Typically the value read from the first source register (rs1)
* Second ALU Operand (**b**): Typically the value read from the second source register (rs2) or an immediate value, depending on the instruction type and control signals

- ALU Result (**result**): Output of the arithmetic logic unit
- Register Write Data (**wd**): The value being written back to the register file after instruction execution

These signals provide all the crucial insight into the internal state of the processor during execution for diagnosing issues and confirming correct behavior.
